# Zapier Catch Hook → ImprovMX `hello@`

## Create the Catch Hook (2 minutes)

1. Open [Zapier Zaps](https://zapier.com/app/zaps) and click **Create → Zaps**.
2. Trigger: **Webhooks by Zapier** → **Catch Hook**.
3. Click **Continue** — copy the **Custom Webhook URL**  
   (looks like `https://hooks.zapier.com/hooks/catch/XXXX/YYYY/`).
4. Leave the Zap on for now (you can finish ChatGPT steps later). Name it:  
   `Sharada Soft — Router (hello@ Catch Hook)`.

## Point ImprovMX (or paste URL here in chat)

On [Aliases](https://app.improvmx.com/domains/sharadasoft.com/aliases), set **hello** forward to:

```text
goverdhan.c@gmail.com, https://hooks.zapier.com/hooks/catch/XXXX/YYYY/
```

(Keep the Gmail address first so you always get a human copy.)

## Test

Email `hello@sharadasoft.com` from a personal address.  
Zapier Catch Hook should show a new request; Gmail should also receive the message.
